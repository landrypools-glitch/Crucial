Deploying Landry Pools CRM to Vercel

Step-by-step instructions to push this app live in under 2 minutes.

1 Save Code to a Local File

Ensure the code above is saved as index.html inside a project folder on your computer.

2 Push to GitHub

Initialize git in your folder and push to a new GitHub repository:

git init
git add index.html
git commit -m "Initial commit - Landry Pools CRM"
git branch -M main
git remote add origin https://github.com/your-username/landry-pools-crm.git
git push -u origin main

3 Import Project into Vercel

  • Log in to your Vercel Dashboard.
  • Click Add New... > Project.
  • Select your landry-pools-crm repository from GitHub and click Import.
  • Leave build settings as default (static HTML requires no build command) and click Deploy.

Instant Live URL

Vercel will build and assign a secure HTTPS URL (landry-pools-crm.vercel.app) instantly, with automatic SSL and global CDN caching.
